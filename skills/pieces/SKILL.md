# Pièces

Outils PageLab à appeler :

- `pieces_manquantes` : pièces attendues encore manquantes d'un dossier.
- `pieces_a_valider` : pièces reçues dont le rangement attend l'avocat.
- `deposer_pieces` : ouvre la fenêtre de dépôt (les fichiers ne passent pas par la conversation).
- `preparer_relance` : brouillon de relance des pièces manquantes.

Le rangement d'une pièce se valide dans PageLab, au clic de l'avocat.
