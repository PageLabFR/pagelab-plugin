# Sources

Outils PageLab à appeler :

- `chercher_texte` : article de code, loi, décret, conventions collectives (Légifrance).
- `chercher_jurisprudence` : décisions de justice (Judilibre).
- `verifier_citations` : vérifie chaque référence d'un texte collé.

Ne cite que les références renvoyées par ces outils, avec leur lien officiel.
