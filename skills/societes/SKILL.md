# Sociétés

Outils PageLab à appeler :

- `closing_dossier` : avancement, éléments par statut, bloquants.
- `preparer_relance_closing` : brouillon de relance d'un élément.
- `preparer_document_societe` : procès-verbal, ordre de mouvement, transmission, formalités.

Rien n'est signé ni envoyé.
